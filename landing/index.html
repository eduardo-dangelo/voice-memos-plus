Stack

Layer new takes over what you already recorded.

Overdub with a monitor mix so harmony, percussion, or a second vocal lands in the same memo. Headphones recommended for a clean stack.

  • Record a new layer while hearing what you already captured.
  • Keep everything in one memo — no bouncing between apps.

Edit track

Trim, move, and balance every layer.

Scrub the waveform, cut what you don’t need, slide clips into place, then set volume, mute, or solo so the mix stays clear while you work.

  • Trim and reposition clips with waveform precision.
  • Mute, solo, and level each layer independently.

Effects

Reverb, delay, and EQ on each layer.

Treat every track like its own channel strip — add space, echoes, and tone without bouncing out to another app.

  • Apply reverb, delay, and EQ per layer.
  • Hear changes in context with the rest of the stack.

Fade

Soft starts and clean endings.

Shape fade-in and fade-out per layer so stacked takes breathe in and out instead of clicking at the edges.

  • Set fade-in and fade-out length on each layer.
  • Curve the fade so entries and exits feel natural.

Long press track menu

Hold a track for every option.

Long-press a layer to open its menu — rename, change color, loop the track, merge, export, or delete without hunting through separate screens.

  • Long-press any track to open its actions.
  • Rename, recolor, merge, export, or remove from one place.

Loop

Practice and polish inside a region.

Set a loop on the timeline and repeat a section while you stack, replace, or listen — perfect for refining a phrase.

  • Drag loop start and end on the timeline.
  • Keep cycling a section while you overdub or edit.

Loop track

Turn a short take into a lasting bed.

Loop an individual track for a set duration so a groove, pad, or ostinato keeps running under new layers.

  • Repeat a single layer without re-recording it.
  • Set how long the track keeps cycling under the mix.

Merge layers

Flatten when you’re ready.

Combine layers into one when the stack is locked — simplify the project and keep moving.

  • Merge selected layers into a single track.
  • Reduce clutter once the arrangement is set.

Export

Share a mix or save the project.

Export m4a or wav for sharing, or a Project (.vmp) so layers and settings come back intact.

  • Share a finished mix as m4a or wav.
  • Save a Project file to reopen layers later.

Metronome & grid

Stay locked to the beat.

Set BPM and time signature, hear a click with optional precount, and see grid lines on the timeline so stacks and edits land in time.

  • Metronome with BPM, time signature, and precount.
  • Beat grid lines on the waveform for visual timing.
